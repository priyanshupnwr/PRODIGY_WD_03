# PRODIGY_WD_03 - Tic Tac Toe Web Application

## Overview

This project is submitted as **Task 03** for the **Prodigy InfoTech Web Development Internship**.

The objective of this task was to develop an interactive Tic Tac Toe game using HTML, CSS, and JavaScript. The application allows two players to play against each other, detects winners and draws, and maintains the game score.

---

## Features

- Two-Player Gameplay (X vs O)
- Winner Detection
- Draw Detection
- Winning Cell Highlight
- Live Game Status
- Scoreboard
- New Game
- Reset Score
- Responsive Design

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
